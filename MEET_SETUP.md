# LiveKit Meet Integration Setup

This guide explains how to set up LiveKit Meet with Campfire.

## Overview

Instead of custom voice controls, Campfire integrates with [LiveKit Meet](https://github.com/HowieDuhzit/meet) - a full-featured video conferencing app built with LiveKit Components.

## Architecture

- **Campfire (Rails)**: Generates LiveKit tokens and provides room context
- **LiveKit Meet (Next.js)**: Handles video/voice UI and user experience
- **LiveKit Server**: Handles media routing and WebRTC

## Setup Steps

### 1. Clone LiveKit Meet

```bash
git clone https://github.com/HowieDuhzit/meet.git livekit-meet
cd livekit-meet
```

### 2. Configure Meet for Campfire Integration

**Update `.env.local` in Meet directory:**

```env
NEXT_PUBLIC_LIVEKIT_URL=wss://your-livekit-server.com
LIVEKIT_API_KEY=your_api_key
LIVEKIT_API_SECRET=your_api_secret
```

**Modify Meet to accept pre-configured rooms:**

Meet should accept URL parameters:
- `room` - Room name (from Campfire: `campfire-room-{id}`)
- `token` - JWT token (generated by Campfire)
- `identity` - User identity
- `name` - User display name

You may need to modify Meet's room page to:
1. Check for URL params first
2. Auto-connect if params are present
3. Skip room creation UI if pre-configured

### 3. Deploy Meet

**Option A: Docker Compose (Recommended)**

Use the provided `docker-compose.meet.yml`:

```bash
docker-compose -f docker-compose.meet.yml up -d
```

**Option B: Separate Deployment**

Deploy Meet as standalone Next.js app:
- Same LiveKit server credentials
- Accessible from Campfire domain
- Configure CORS if needed

### 4. Configure Campfire

**Environment Variables:**

```env
MEET_URL=http://localhost:3001  # Or your Meet deployment URL
LIVEKIT_API_KEY=your_api_key
LIVEKIT_API_SECRET=your_api_secret
LIVEKIT_HOST=wss://your-livekit-server.com
LIVEKIT_HTTP_URL=https://your-livekit-server.com
```

### 5. Test Integration

1. Start Campfire
2. Configure LiveKit in account settings
3. Join a room
4. Click "Join Voice/Video"
5. Should redirect/embed Meet with pre-configured room

## User Experience

### Flow 1: New Window (Default)
1. User clicks "Join Voice/Video" in room
2. Opens Meet in new tab/window
3. Meet auto-connects to Campfire room
4. User controls via Meet UI
5. Close window to return to Campfire

### Flow 2: Iframe Embed (Optional)
1. User clicks "Join Voice/Video"
2. Meet loads in full-screen overlay
3. User controls via Meet UI
4. Click "Back to Room" to close overlay

## Room Naming Convention

Campfire rooms map to LiveKit rooms:
- Format: `campfire-room-{room_id}`
- Example: `campfire-room-123`

User identity:
- Format: `user-{user_id}`
- Example: `user-456`

## Token Generation

Campfire generates JWT tokens with:
- Room join permission
- Publish/subscribe permissions
- 2-hour expiration
- User identity and name

## Modifying Meet

To customize Meet for Campfire:

1. **Auto-connect on load:**
   ```typescript
   // In Meet's room page
   useEffect(() => {
     const params = new URLSearchParams(window.location.search)
     const room = params.get('room')
     const token = params.get('token')
     
     if (room && token) {
       // Auto-connect with provided credentials
       connectToRoom(room, token)
     }
   }, [])
   ```

2. **Hide room creation UI:**
   ```typescript
   const isPreConfigured = !!searchParams.get('room')
   
   if (isPreConfigured) {
     // Hide room creation form
   }
   ```

3. **Add return to Campfire button:**
   ```typescript
   const returnToCampfire = () => {
     window.opener?.postMessage({ type: 'meet-closed' }, '*')
     window.close()
   }
   ```

## Troubleshooting

**Meet not loading:**
- Check MEET_URL is correct
- Verify Meet is running
- Check CORS settings

**Token errors:**
- Verify LiveKit credentials match
- Check token expiration
- Ensure room naming is consistent

**Iframe issues:**
- Check CSP headers allow iframe
- Verify MEET_URL is accessible
- Check browser console for errors
